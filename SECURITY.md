# Reporting integrity and security issues

ONC-AGI is a benchmark. A way to obtain answers, infer which worlds have no signal, bypass scorecard caps, escape the standard-track sandbox, or otherwise score without discovering is a **security issue**: publishing it before it is fixed would void evaluations.

Report it privately through GitHub's **Report a vulnerability** (Security tab → Advisories), not in a public issue. Include the world ids, the commands and what you observed.

Ordinary bugs and interface feedback go in public issues (see [CONTRIBUTING.md](CONTRIBUTING.md)).
